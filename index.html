"🖨️ 인쇄/PDF" – 새 탭에서 열기 (iframe에서 print 불가이므로): 보고서 HTML을 Blob(text/html)으로 만들어 새 윈도우 열기. 새 탭은 iframe 제약이 없으므로 window.print() 정상 작동. 보고서 상단에 "🖨 인쇄하기" 버튼도 포함시킬 것. {AI 호출 시} - "보고서 생성 중..." 로딩 애니메이션 - Gemini API 응답을 마크다운 → HTML로 변환하여 렌더링 CSS 색상: hex/rgb만 (oklch/hsl 금지)
PART 3

자주 묻는 질문

생성된 앱은 어떻게 사용하나요? ▸
AI Studio의 Preview 탭에서 바로 실행할 수 있습니다. 별도 설치나 배포 없이 브라우저에서 동작합니다. 생성된 코드를 복사하여 로컬 HTML 파일로 저장해도 됩니다 (단, Gemini API 기능은 Preview에서만 작동).
Google AI Studio는 무료인가요? ▸
네, Google AI Studio는 무료로 사용할 수 있습니다. Gemini API도 무료 등급(Free tier)이 제공되어 실습에 충분합니다. 대량 사용 시에는 유료 전환이 필요할 수 있습니다.
엑셀 데이터는 안전한가요? ▸
업로드된 엑셀 데이터는 브라우저 내에서만 처리됩니다. 서버에 저장되지 않으며, AI 분석 시에는 요약된 수치만 Gemini API로 전송됩니다. 원본 데이터 전체가 전송되지는 않습니다.
내 회사 엑셀도 사용할 수 있나요? ▸
네! 프롬프트의 데이터 컬럼 구조 부분만 여러분의 엑셀 컬럼명에 맞게 수정하면 됩니다. AI가 자동으로 인식하여 대시보드를 만들어줍니다.
Gemini가 오류 코드를 생성하면? ▸
에러 메시지를 그대로 복사하여 같은 대화창에 붙여넣고 "이 에러를 수정해줘"라고 요청하면 됩니다. 바이브코딩의 핵심은 이 반복적인 대화를 통한 개선입니다.
차트가 안 보이거나 깨지는 경우? ▸
Chart.js CDN이 로드되지 않는 경우일 수 있습니다. 프롬프트의 기술 스택 부분에 명시된 CDN URL이 정확한지 확인하세요. 브라우저 콘솔(F12)에서 오류 메시지를 확인하면 원인을 파악할 수 있습니다.
폰트가 이상해요 ▸
CSS에서 한글 폰트를 명시적으로 지정하지 않으면 기본 폰트가 사용됩니다. 프롬프트에 "맑은 고딕" 또는 "Noto Sans KR" 등 원하는 폰트를 지정해 주세요.
모바일에서도 되나요? ▸
기본적으로 반응형으로 생성되지만, 복잡한 대시보드는 PC 환경에서 사용하는 것을 권장합니다. 모바일 최적화가 필요하면 "모바일 반응형으로 만들어줘"라고 추가 요청하세요.
PDF로 내보내려면? ▸
STEP 4의 보고서 탭에서 "🖨️ 인쇄/PDF" 버튼을 클릭하면 새 탭에서 보고서가 열립니다. Ctrl+P (또는 Cmd+P)로 인쇄 대화상자를 열고, "PDF로 저장"을 선택하면 됩니다.
