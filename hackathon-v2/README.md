# 해커톤 5부 설계도 작업대 v2

2026 NI2.0 AID 해커톤 대회(신산업분야 특화 선도전문대학 2.0) 본선(11/26~27, 해운대 마리안느 호텔) 현장용 참여형 웹앱. 단일 HTML, 서버·로그인·외부 CDN 없음.

## 파일
- `index.html` — 배포·사용본 (더블클릭으로 열림, 오프라인 OK). 사용자 전달 사본: `downloads/해커톤_5부_설계도_작업대_v2.html`
- 웹 주소: https://jeonggunhwa.github.io/ai1/hackathon-v2/ (깃허브 `jeonggunhwa/ai1` 저장소의 `hackathon-v2/` 폴더, main 브랜치 루트 = Pages)
- `preview/` — 검증 스크린샷과 결과 기록지 샘플 PDF(3쪽)
- `src/` — 재생성용 소스 조각(헤드 CSS·1~5부 HTML·데이터·로직)과 `build.sh`

## 고칠 때
1. `src/` 안의 해당 조각을 고친다 (예: 문구는 `1*_part*.html`, 프롬프트 템플릿은 `20_data.js`).
2. 작업실 루트에서 `cp documents/hackathon_v2/src/*.html documents/hackathon_v2/src/*.js .build/` 후 `sh documents/hackathon_v2/src/build.sh` → `index.html` 재생성 (`build.sh`는 `.build/`와 루트 기준 경로를 씀).
3. `downloads/` 사본도 다시 복사하고, 드라이브 파일을 교체 업로드한다. 웹도 같은 파일을 `deploy/ai1/hackathon-v2/index.html`에 복사해 커밋·푸시한다.

## 현황판 연결 방법(강사용) — 지금 연결된 방식
1. 스프레드시트: https://docs.google.com/spreadsheets/d/1IFDW-hfiDjro5tIEddxF9V8zYNTDbQJChkNz-5dtxak/edit (드라이브 `00_피클x클로드_통합작업실/01_강의·교육자료`)
2. **제출 경로 = 구글 폼** `2026 NI2.0 AID 해커톤 제출 (웹앱 자동 기록)` → 응답이 같은 시트의 `제출로그` 탭으로 들어가고 `팀별현황판`이 수식으로 집계합니다. 앱은 `src/20_data.js`의 `FORM_ACTION`·`FORM_ENTRIES`로 전송합니다(브라우저 CORS 문제 없이 바로 저장됨, 2026-11-25 E2E 확인).
3. (선택) Apps Script 웹앱 방식: `apps_script/Code.gs`를 시트에 바인딩해 배포하면 서버가 정시/지각·점수를 직접 계산하고 doGet으로 앱 안 대시보드까지 가능합니다. 주소를 `SUBMIT_ENDPOINT`에 넣으면 폼 대신 이 경로를 씁니다(배포에는 계정 2단계 인증 1회 필요).
4. 주의: 폼 전송은 브라우저에서 **결과를 읽지 못하는 방식(no-cors)** 이라, 앱은 ‘전송 시도’를 성공으로 표시합니다. 실제 기록은 반드시 `제출로그` 시트에서 확인하세요.
5. 중복 제출: 같은 팀·단계를 다시 제출하면 `제출로그`에 줄이 하나 더 쌓입니다. `팀별현황판`의 총점은 0부는 합계, 1~5부는 **그 단계의 마지막 점수**로 계산됩니다.
